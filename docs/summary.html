Components.

Four areas, one app. Every area has its own access level.
What the app contains
Desk/desk · desk PIN
  • Big search (ignores accents and case)
  • QR scanner button
  • Guest card + 72px CHECK IN
  • Welcome message + Undo
  • VIP / wheelchair banners
  • Call manager button
  • Walk-in form
  • Live counter
Manager/manager · manager PIN
  • Live Arrivals + alerts
  • Guests: raw vs cleaned
  • Walk-in approvals
  • Duplicate review
  • Tickets: QR + CSV links
  • Excel import
  • Client report (.xlsx)
  • Do-not-admit override
Guest ticket/t/[token] · public link
  • Personal QR code
  • Random 128-bit token
  • No personal data in the QR
  • Can be reissued
Galaxy wall/wall/[key] · secret link
  • Big-screen animation
  • Arriving companies
  • Live count
  • No guest names

Database tables.

importsEach Excel upload
registrationsRaw row + cleaned fields
peopleOne real person
duplicate_suggestionsStrong / medium / weak
checkinsMax 1 active per person
walkinsWait for approval
alertsVIP, access, help calls
audit_logEvery action
login_attemptsPIN rate limit
Many registrations can point to one person. Check-in is per person, so a confirmed duplicate is admitted once.
